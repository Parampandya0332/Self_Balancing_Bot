# Self Balancing Bot

A two-wheel self balancing robot developed using ESP32, MPU6050, and PID control.

## Features

- Real-time balancing
- PID based stabilization
- MPU6050 angle sensing
- ESP32 microcontroller
- Motor driver based control

## Hardware Used

- ESP32
- MPU6050
- Rhino Motor Driver
- DC Geared Motors
- LiPo Battery

## PID Equation

u(t) = Kp*e(t) + Ki∫e(t)dt + Kd(de/dt)
